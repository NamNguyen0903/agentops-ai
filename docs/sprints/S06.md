### 5.2 Evidence contract

The evidence domain must support:

| Field | Meaning |
|---|---|
| id | Stable evidence identifier |
| task_id | Task isolation boundary |
| title | Bounded source title |
| source_url | Original source URL |
| retrieved_url | Final validated URL |
| excerpt | Bounded source content |
| acquisition_method | Application-owned acquisition provenance |
| retrieved_at | UTC retrieval timestamp |
| published_at | Nullable publication timestamp |
| content_hash | Content integrity metadata |

Exact types, storage constraints, deduplication keys
and repository operations must be derived from
existing source contracts before implementation.

Owner and attempt isolation must not be delegated
to model-supplied identifiers.

Do not introduce durable worker attempts or task
lifecycle mutations through the evidence schema.

Where no authorized durable attempt exists, use
an application-owned isolated execution context.

No fabricated provenance, retrieval timestamps or
publication dates.

No hidden chain-of-thought, credentials or complete
fetched pages in graph state.

workflow are not established.

AC07:
DNS all-answer validation, numeric binding, redirects
and TLS safeguards have isolated verification.
Integrated local TLS tests substitute the connection
seam. They do not establish full actual connector-chain
security from DNS to the connected peer and TLS.

AC09:
Search/retrieval counters, shared transient retry,
bounded socket operations and deadline propagation
have local verification. Actual external usage and
end-to-end provider limits are not fully verified.
OS DNS lookup cancellation and hard process
interruption are not established.

deadlines from hard interruption. Lack of hard
cancellation alone is not a newly imposed acceptance
criterion. Adapter capability and live execution
approval remain separate obligations.

AC21:
Cannot be fully verified while SG06, SG08 and SG10
retain partial security evidence.

  synthetic-only.

  not full fetched-page integrity.
- Citation validation is structural, not proof of
  semantic factual grounding.

  a database row-level security guarantee.
